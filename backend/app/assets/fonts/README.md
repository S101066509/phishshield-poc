# PDF 中文字型

報告使用 Noto Sans TC，依 SIL Open Font License 1.1 隨原始碼提供。授權全文保存在 [NotoSansTC-OFL.txt](NotoSansTC-OFL.txt)。

來源為 [Google Fonts 的 Noto Sans TC](https://github.com/google/fonts/tree/main/ofl/notosanstc)。下載官方 NotoSansTC[wght].ttf 後，以 fontTools 4.68.0 的 instantiateVariableFont 將 wght 固定為 400，並更新字型名稱為 Regular。執行期直接使用隨附 TTF，PDF 以子集方式內嵌字型。

原始可變字型 SHA-256 為 864727d210d54f2537bbe23b3a839436c3992af72de9322af5270897246bd44f，Regular 字型 SHA-256 為 c46c705f146b24d164e19e194d7f5006cab35720d930ce0d81696e4130d39f89。
